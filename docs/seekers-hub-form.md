# The Seekers' Hub job form

Generated by `python -m stemed_jobs.submitted --write-spec`. Do not edit by hand.

Build these fields on the Seekers' Hub form, in this order, with **exactly** these field names and
choices, and have each submission emailed to the editor with every field and its name. The editor
pastes that email into the GitHub issue template "Add a submitted position (editors)" and adds the
approved label; the position then appears on STEMEd+ Jobs. No blog post is needed.

## 1. Position title

- Type: single line of text
- Required: yes

## 2. Institution or organization

- Type: single line of text
- Required: yes
- Help text: Its full name, not an abbreviation.

## 3. Location

- Type: single line of text
- Required: yes
- Help text: City and state or country, or Remote.

## 4. Who is this position for?

- Type: checkboxes (at least one)
- Required: yes
- Choices:
    - Graduate Student
    - Postdoc
    - Faculty
    - Professional Staff

## 5. Disciplines

- Type: checkboxes (choose any)
- Required: no
- Help text: Leave blank if none fit; we will sort it by its text.
- Choices:
    - Agriculture
    - Bioscience
    - Chemistry
    - Earth Science
    - Engineering
    - Health Education
    - History & Philosophy of Science
    - Human Dimensions
    - Learning Science
    - Mathematics
    - Physics
    - Science & Health Communication
    - Science Education

## 6. Link to the official posting

- Type: website address (URL)
- Required: yes
- Help text: Where applicants read the full ad and apply.

## 7. Application deadline

- Type: date, or the word rolling
- Required: no
- Help text: e.g. January 15, 2027, or rolling.

## 8. Review of applications begins

- Type: date
- Required: no
- Help text: Only if the ad says when review begins.

## 9. Description

- Type: paragraph text, up to 2000 characters
- Required: yes
- Help text: A short summary of the position.

## 10. Your name and email (for the reviewer only)

- Type: single line of text
- Required: yes
- Help text: Only the editor sees this; it is never published.

Put the contact field last, so nothing after it is read into the position.
